## Four selection questions

1. **Outcome/decision:** determine whether a concrete request-led response is useful enough for an outside agent to adopt or amend. A possible downstream beneficiary is the represented small business; its human ownership, income and poverty relevance are not established.
2. **Cheapest evidence:** a single reviewed public reply in the original thread, only after Hermes clears ownership and scope, followed by an actual voluntary answer. No application, code project, paid campaign or private records are needed.
3. **Multiplier and alternatives:** use the recipient's existing tracking and an already permitted channel. Credit, donation, inventory purchase, paid advertising and a new dashboard are unnecessary. Simply answering the question is cheaper than building an unrequested tool. Existing replies may already be sufficient; that is a kill condition, not a reason to compete.
4. **Falsifier:** the recipient declines, prior advice already supplies the same plan, Hermes finds a duplicate/owner conflict or contact restriction, no usable existing channel exists, or a useful response would require spending, private analytics, customer identifiers or unsupported claims. No response after the fixed window means this response test failed to show uptake, not that organic marketing never works.
